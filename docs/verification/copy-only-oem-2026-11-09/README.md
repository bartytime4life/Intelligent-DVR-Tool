## Operator outcome

The Linux/Windows DVR Companion shortcut now opens verified folder backup without
requiring trained weights or an analysis catalog. The normal Python 3.12/CPU
installation still applies. A configured existing catalog remains available;
without one the interface reports Copy-only mode and disables automatic analysis.
The API independently refuses analysis in this mode. Nothing copies on startup.

An owner-only local library session issues the existing server token without
creating Jobs or live inference. Host, origin and token controls remain; Linux
session access retains the same-account socket check. Copy-only settings use a
private installation-local store. Adding a model reuses that store, while older
catalog-adjacent stores keep their location. Check examines folder readiness
without creating settings or starting work. No migration deletes old data.

Do not aggregate these rows into a qualification percentage or count generated
passes as field evidence. Training/calibration samples must remain separate from
held-out evaluation. Detection quality and track association are distinct:
[SciSpace's HOTA record](https://scispace.com/papers/hota-a-higher-order-metric-for-evaluating-multi-object-2htakwu8um)
and the [authors' primary paper](https://arxiv.org/abs/2009.07736) describe separate
detection, association and localization contributions. That supports retaining
the existing [tracking evaluator](../../tracking-evaluation.md) separately from
[detection evaluation](../../offline-evaluation.md); it is not evidence that this
project has achieved any HOTA or recognition score. No detector implementation was changed.
