# November 1 visual guide assets

[Visual handbook](../../how-to.md) · [Screenshot atlas](../../visual-atlas.md) · [Manifest](manifest.json) · [Dated collections](../README.md)

This collection adds **twelve actual application captures**, **ten authored vector
workflow diagrams**, and **one AI-generated conceptual illustration**. They serve
different purposes. The screenshots show controls; diagrams explain a procedure;
the hero establishes the camera/clip/review/plan relationship visually. None
qualifies real recognition, camera compatibility, site measurements or capacity.

## Actual interface captures

Source: merged `main` [`2566d845fbbc7b9f54f98441009a604f2fa513ce`](https://github.com/bartytime4life/Intelligent-DVR-Tool/commit/2566d845fbbc7b9f54f98441009a604f2fa513ce), through PR #71. The frontend was built from that source for a clean local service and an isolated browser origin. Default browser viewport: **1280 × 720**; `recognition-setup.jpg` is a native full-page capture. Images were compressed to JPEG with macOS `sips`, quality 83, without adding controls or changing content.

No real webcam, microphone, GPS, map provider, private recording or face template
was used. Recognition's `guide-generated-example.webm` is a generated 30-frame
flat-color clip. The ONNX fixture emits constant boxes. Its six sampled detections
and the derived observation exercise the workflow; they establish no detector
accuracy and depict no actual person. No enrollment consent was given or
biometric baseline created for these captures. The user's normal DVR origin and
private runtime folders were kept separate.

To recreate the example, build the exact source, use the generated fixture in
[tests/local_analysis_fixture.py](../../../tests/local_analysis_fixture.py), select
a separate private test catalog/recordings folder and loopback port, then navigate
the visible controls. Do not borrow the owner's recordings or browser state.
Screenshots are illustrative references, not pixel comparison test fixtures.

## Editable workflow diagrams

The ten `.svg` files are original, code-authored diagrams generated by
[scripts/build-guide-graphics.py](../../../scripts/build-guide-graphics.py).
Each has a title/description and uses the application's navy, teal and amber
palette. They contain no scripts, linked resources, embedded footage or tracking.
The full instructions remain readable in the linked Markdown guides.

```bash
python3 scripts/build-guide-graphics.py
python3 scripts/build-guide-graphics.py --check
```
